# The Reality Remix - Web App (PWA)

Progressive Web App for The Reality Remix - turn everyday life into instant entertainment using Gemini 2.0 Flash.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Usage

1. Start the backend server first
2. Click "Start Camera" and allow permissions  
3. Choose a commentary genre
4. Click "Start Commentary"
5. Point your camera at anything and enjoy!

## Available Genres

🌿 Nature Documentary | 🏆 Sports | 🕵️ Thriller | 💕 Rom-Com  
😱 Horror | 👨‍🍳 Cooking Show | 🔬 Science | 📺 Reality TV

## Browser Support

Works on Chrome, Safari, Firefox, Edge (desktop & mobile)
